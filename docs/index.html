What it handles so you don't have to

Every one of these cost someone a weekend. They're written up in Why it breaks.

no system ROCm

Nothing to layer

The ROCm PyTorch wheels carry their own runtime. All your distro needs is the amdgpu kernel driver, which it already has.

iGPU trap

Pins the right card

Ryzen iGPUs show up as a second ROCm device. ravn reads the KFD topology and pins apps to the big one.

overrides

Correct per GPU

RX 6600, 6700 XT, Steam Deck: works out the HSA_OVERRIDE_GFX_VERSION from the kernels inside your PyTorch, per app, never globally.

self-healing

Survives custom nodes

A node pip-installs CUDA torch or plain triton? ravn notices before launch and puts the ROCm build back.

Three commands

Everything lives in ~/ravn. Outside it ravn adds a launcher, a menu entry and, if you ask, a systemd user unit.

ravn install comfyui Python 3.12 venv, ROCm PyTorch, ComfyUI-Manager, an optional 2 GB starter model. Then a real matmul on the GPU proves it works.
ravn run comfyui --open starts it with the right environment and opens the browser. Also in your app menu as ComfyUI (ravn).
ravn install ollama then ravn enable ollama: the official ROCm build in user space, running at login, CUDA libraries stripped.
